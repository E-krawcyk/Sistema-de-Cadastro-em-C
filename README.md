# Sistema de Cadastro em C

Projeto desenvolvido em C com o objetivo de cadastrar e consultar dados utilizando arquivos de texto.

O sistema foi dividido em dois programas:

- **Cadastro.c**: responsável por registrar os dados informados pelo usuário em um arquivo de texto.
- **ConsultaCadastro.c**: responsável por pesquisar os registros cadastrados utilizando o número de telefone.

## Funcionalidades

- Cadastro de nome, sobrenome, telefone e data de nascimento
- Armazenamento dos dados em arquivo de texto
- Consulta de registros pelo telefone
- Validação básica das opções informadas pelo usuário
- Possibilidade de realizar múltiplos cadastros e consultas

## Conceitos utilizados

Durante o desenvolvimento foram utilizados conceitos como:

- Estruturas condicionais
- Estruturas de repetição
- Vetores de caracteres
- Manipulação de strings
- Entrada e saída de dados
- Manipulação de arquivos com `FILE`
- `fopen`, `fclose`, `fprintf`, `fscanf` e `fgetc`
- Validação de entrada

## Objetivo do projeto

O projeto foi desenvolvido como parte dos meus estudos em programação em C, com foco na aplicação prática de lógica de programação e manipulação de arquivos.

A proposta foi criar um sistema simples capaz de armazenar informações de forma persistente e permitir a consulta posterior dos dados cadastrados.
